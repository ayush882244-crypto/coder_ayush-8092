# S & AI Digital Detective

## About This Project

The S & AI Digital Detective is a Diwali learning assignment focused on understanding computer fundamentals, operating systems, Terminal commands, Python programming, number systems, Git, GitHub and computer networking.

The purpose of this project is to explore how computers work through practical activities and document the learning process.

- Computer hardware and software
- Input, Processing, Output and Storage (IPOS)
- Terminal and command-line operations
- Operating system and process management
- Python programming
- Binary, decimal and hexadecimal number systems
- ASCII and UTF-8 encoding
- Git version control and GitHub collaboration
- Computer networks and DNS
